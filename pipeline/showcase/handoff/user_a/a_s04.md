**User:** We're using an LLM to pull variant-phenotype mentions out of papers for a literature review. Running the same paper twice gives slightly different lists. How worried should I be about reproducibility?

**Assistant:** Some variation is expected. It matters most if the differences change your conclusions. Measure it before deciding: run each paper several times and check how often the extracted items agree.

**User:** Here's a screenshot of two runs on the same paper. The second run missed two variants.

**Assistant:** Missing items between runs suggests recall is the weak spot. Track agreement per item, not just per paper, so you can see which mentions are unstable.

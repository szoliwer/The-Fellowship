**User:** I ran scVelo on my hematopoiesis data and most of the velocity arrows point from stem cells toward erythroid cells, which is what I expect. But a chunk of the megakaryocyte progenitors have arrows pointing backwards, toward the stem cluster. I'm not sure if that's real biology or the method breaking. How much should I trust the direction of these arrows for saying which way differentiation goes?

**Assistant:** Some caution is warranted. RNA velocity relies on the ratio of unspliced to spliced reads and assumes fairly constant kinetic rates across a population. In hematopoiesis, a well-known failure case involves transcriptional boosts, where a set of genes sharply increases transcription during erythroid maturation, which can flip inferred directions. Megakaryocyte and erythroid lineages share a progenitor and some of these genes. Check which genes drive the backward arrows using per-gene phase portraits; if a few genes with odd kinetics dominate, the reversal is probably an artifact.

**User:** I looked at the phase portraits and yes, a handful of genes have that weird two-arm shape. When I drop them the backward arrows mostly go away. But now I feel like I'm cherry-picking genes until I get the answer I expected. Is there a principled way to decide which genes to exclude, rather than just removing whatever disagrees with my prior?

**Assistant:** That's a healthy worry. More principled options include: using scVelo's likelihood or fit-quality scores and excluding genes below a threshold set before looking at directions; using the differential kinetics test, which flags genes with multiple kinetic regimes across clusters; or switching to methods that allow cluster-specific rates. Report results with and without the exclusions, and state the criterion up front. Independent evidence, like metabolic labelling or lineage tracing, is the strongest way to confirm direction rather than relying on velocity alone.

**User:** We now have a lineage-tracing experiment in the lab where hematopoietic stem cells carry heritable DNA barcodes, and we profiled the same cells with scRNA-seq at two timepoints. I want to use the clonal information as ground truth to score how well the computational methods I've been using actually recover fate relationships. I'm not sure how to turn clone labels into a fair benchmark though.

**Assistant:** That's a valuable setup. A common approach: use early-timepoint cells whose clones are also observed at the later timepoint, and define each early cell's 'true' fate bias as the fraction of its clonal siblings in each mature lineage at the later timepoint. Then compare that with each method's predicted fate probabilities for the same early cells, using correlation or AUROC for predicting the dominant fate. Restrict to clones with enough later cells to give a stable fraction, and report how many cells meet that criterion.

**User:** That makes sense. One complication is that only around 20 percent of barcodes get recaptured at the second timepoint, so I'm worried the evaluation set will be small and biased toward large, proliferative clones. I suspect those might be exactly the clones where prediction is easiest. Is there a way to correct for that?

**Assistant:** Your concern about selection bias is legitimate. Options include stratifying the evaluation by clone size so you can see whether performance differs for small versus large clones, weighting each clone equally rather than each cell, and using a minimum clone size threshold but reporting results at several thresholds. You could also simulate subsampling of large clones to match the size distribution of small ones. Being explicit that the benchmark is conditional on clone recapture is important, since methods may perform worse on rarer fates.

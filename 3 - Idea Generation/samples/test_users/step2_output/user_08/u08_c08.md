**User:** A collaborator has a big set of fluorescence microscopy images of tissue sections and wants nuclei and cell boundaries segmented. I've only used classic watershed before. Should we go straight to a deep learning tool like Cellpose or StarDist? I'm worried about cells that are densely packed and overlapping, which is where watershed always failed for me.

**Assistant:** For dense tissue, deep learning tools are generally a big improvement over watershed. StarDist represents nuclei as star-convex polygons, which works very well for roundish nuclei but struggles with irregular cell shapes. Cellpose predicts flow fields toward cell centres, which handles irregular and touching cells better, and has generalist pretrained models for both nuclei and whole cells. A sensible plan is to run pretrained Cellpose on a few representative images, inspect errors, and then fine-tune with a small number of manually corrected annotations if needed.

**User:** Fine-tuning with a few corrected images sounds doable. How would we know the segmentation is good enough, though? I don't want to just eyeball it. I assume we need a held-out set of hand-annotated images and some metric, but I'm not sure whether pixel accuracy is meaningful for this.

**Assistant:** Pixel accuracy can be misleading because background dominates. Instance-level metrics are better: match predicted and true objects by intersection over union, then compute average precision across IoU thresholds, typically from 0.5 to 0.9. Also report counts of merges and splits, since those errors matter most for downstream single-cell measurements. A held-out set of a few hand-annotated images covering different tissue regions is a good start. Ideally have two people annotate a subset to estimate inter-annotator agreement as a ceiling.

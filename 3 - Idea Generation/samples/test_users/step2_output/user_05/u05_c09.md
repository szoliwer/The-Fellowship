**User:** Almost done with the class size RD. Main result: a reduction of about five students raises math scores by 0.1 standard deviations, with smaller effects for reading. Now I want to talk about mechanisms. I have teacher surveys on time spent on individual instruction and on discipline, but only for a subset of schools. I worry that using a mediator in the RD framework means I'm sneaking in extra assumptions. How should I frame this?

**Assistant:** You are right to be careful. The RD identifies the total effect of class size, but splitting it into mediated pathways requires additional assumptions, such as no unobserved confounding between mediators and outcomes, which the design does not deliver. One honest approach is to estimate the RD effect of class size on each mediator as an outcome itself. That tells you smaller classes change teacher time use, without claiming how much of the score effect runs through it. Also check that the survey subset is balanced around the cutoffs, otherwise selection into the survey could bias things.

**User:** Yes, I'll treat the mediators as outcomes and not run any decomposition. The survey subset is mostly from the earlier years, before the enforcement change, so I'll have to note that. Honestly I'm also thinking about a follow-up where I combine this with administrative data on teacher turnover, because smaller classes might help retain teachers, which would be a longer-run channel nobody seems to measure well.

**Assistant:** That follow-up sounds promising. Teacher retention is plausibly affected by class size through workload and job satisfaction, and administrative data would let you track it over several years. The same RD design could work with turnover as an outcome, though you would need to think about how teacher assignment interacts with class splits. For example, schools that split a class may hire newer teachers, which mechanically affects turnover. Separating the effect on incumbent teachers from the composition effect of new hires would make the analysis much more convincing.

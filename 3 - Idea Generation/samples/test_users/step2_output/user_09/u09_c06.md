**User:** I've been wondering whether open post-publication review on preprints could counteract citation bias. My worry is that positive results get cited more than null results, and public comments might be one place where people point to null studies that the authors ignored. Is that plausible, or am I connecting two unrelated things?

**Assistant:** It's plausible as a mechanism, though probably weak in practice. Public commenters sometimes note missing references, including contradicting or null studies, and authors may add them in revision. But commenting rates are low, so the aggregate effect on citation patterns would be small. A testable version is narrower: among preprints that received substantive public comments, how often did the comments request additional citations, and were those citations disproportionately to null or contradicting work?

**User:** That narrower version is doable. I could code the comments for whether they ask for missing citations and whether those are null results. Then compare reference lists between the preprint and published version. If public review does nudge authors toward citing null findings, that would be a nice small result.

**Assistant:** Yes, and it pairs well with your broader citation bias work. You'd need a way to classify the newly added references as positive, null or mixed, which could reuse your existing coding scheme. Be prepared for a small sample; you may need to pool across several preprint servers or disciplines. Even a descriptive finding, such as what fraction of comments request citations at all, would be informative.

**User:** I'll pool across servers. Part of me suspects the effect will be close to zero, but even a clear null would be worth publishing, which is kind of the whole point of my citation bias argument. If null results deserve to be cited, my own null result deserves to be written up properly too.

**Assistant:** That's a nicely consistent stance. Pre-registering the analysis would make a null result more credible and harder to dismiss. You could also report an equivalence test to show the effect is reliably small rather than just not significant. Framing it that way demonstrates the kind of null reporting you're advocating for. It would also be worth stating in advance what effect size you would consider practically meaningful, so readers can judge the result against a clear benchmark.

**User:** I have a LaTeX table with nine columns of sampling data and it runs off the right side of the page. I'm using a standard tabular environment inside a table float, article class, normal margins. I tried making the font smaller with small but it's still too wide. What's the easiest fix that doesn't make it unreadable?

**Assistant:** A few options, from simplest to most flexible. Wrap the tabular in a resizebox from the graphicx package, scaling it to the line width; this is quick but can shrink text a lot. Alternatively, use the tabularx package with X columns so text wraps within cells. You can also reduce column padding by setting tabcolsep to something like 4pt. If the table is truly wide, putting it in a landscape page using the pdflscape package often gives the most readable result.

**User:** Setting tabcolsep to 4pt plus switching to footnotesize got it almost there, but one column with long site descriptions is still the problem. It has entries like 'secondary clarifier outlet, north side, upstream of chlorination' which push everything wider. I'd rather not abbreviate them because reviewers asked for full descriptions. Can I make just that one column wrap onto multiple lines while the numeric columns stay as they are?

**Assistant:** Yes. Replace that column's l specifier with p{3cm}, or whatever width fits, and the text will wrap inside the cell while the other columns stay unchanged. If you want the wrapped text vertically centered relative to the numeric cells, load the array package and use the m{3cm} column type instead. Another option is tabularx with an X column, which automatically takes whatever horizontal space is left. For narrow wrapped columns, adding raggedright through the array package's greater-than syntax avoids awkward stretched word spacing. Since your numeric columns stay as r or c, their alignment won't be affected.

**User:** I have a folder of about 600 microscope images with useless names like IMG_0423.jpg. I want to rename them to the date and time they were taken, like 2026-05-14_093212.jpg. Can you write a Python script that reads the EXIF date and renames them, and falls back to the file modification time if there's no EXIF?

**Assistant:** Here's a compact approach using Pillow. Loop over files in the folder with pathlib, open each with Image.open, and call getexif(). The DateTimeOriginal tag is 36867, but on many cameras it sits in the Exif sub-IFD, so check get_ifd(0x8769) as well, and fall back to tag 306 (DateTime). Parse the string with datetime.strptime using the format %Y:%m:%d %H:%M:%S. If no tag is found, use datetime.fromtimestamp(path.stat().st_mtime). Format the result with strftime('%Y-%m-%d_%H%M%S'), and if that name already exists, append a counter like _1 before the extension. Finally call path.rename(new_path). Run it with a dry-run flag first that only prints the planned renames.

**User:** Thanks, the structure makes sense. Two complications: some images were taken within the same second because of burst capture, so the counter is definitely important or files will overwrite each other. Also about a third of the files are .tif rather than .jpg, exported from the microscope software. Does Pillow read EXIF dates from TIFF files, and how do I make the loop pick up both extensions?

**Assistant:** Pillow can read TIFF tags with getexif() as well, though microscope software sometimes stores acquisition time in its own metadata instead of the standard DateTime tag. If those files lack it, your fallback to modification time will handle them, but check that copying didn't reset the modification times. To catch both formats, loop over folder.iterdir() and keep files whose suffix.lower() is in a set of .jpg, .jpeg, .tif and .tiff. Writing a CSV log of old and new names during the real run also makes it easy to reverse the renaming if anything looks wrong.

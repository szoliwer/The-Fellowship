**User:** Quick one: my y-axis label reads gene copies/16S but my supervisor says the units are unclear. The values are ARG copies divided by 16S rRNA gene copies, so it's a ratio. How should I write it in matplotlib? Also, looking at this plot, I'm honestly not sure qPCR of four ARGs is enough to make the claim we're making. I think we need metagenomics to see the full resistome, but nobody in our group has that experience, so I'd need a collaborator for it.

**Assistant:** For the label, something like ARG copies per 16S rRNA gene copy is clear and unitless. In matplotlib: ax.set_ylabel('ARG copies per 16S rRNA gene copy'). If values span orders of magnitude, a log scale with the label noting log10 helps. On metagenomics, that's a fair concern; targeted qPCR can miss genes outside your panel, and shotgun metagenomics would show the broader resistome and mobile elements.

**User:** The values do span about four orders of magnitude, so I'll switch to a log scale. Should I write log10 in the axis label, or is it enough to just use a log axis and keep the label as it is? I've seen both in papers and I'm never sure which is correct. My supervisor is picky about this kind of thing.

**Assistant:** Both are correct, but they mean different things. If you call ax.set_yscale('log'), the axis itself shows the scale and the tick labels are in linear units, so the label stays as ARG copies per 16S rRNA gene copy with no log10. If instead you plot log10-transformed values on a linear axis, the label should read log10(ARG copies per 16S rRNA gene copy). The log axis approach is usually easier for readers to interpret. Keep minor ticks visible so intermediate values can be estimated.
